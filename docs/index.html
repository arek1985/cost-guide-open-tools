Cost Guide Nederland · Open Tools

ProjectSTSCSKCL

Controleerbare regels voor woningonderhoud

Vier kleine modules met zichtbare invoer, vaste rekenregels en een controleerbaar resultaat. Bedoeld voor wie een werkblad wil begrijpen, een berekening wil narekenen of de code wil beoordelen.

Er staan geen actuele marktprijzen in dit project. De voorbeelden gebruiken fictieve gegevens. De functies verzenden geen gegevens en hebben geen externe afhankelijkheden.

ST-M10

Oppervlakte van vlakken en openingen narekenen

Noteer de afmetingen van ieder rechthoekig vlak en van de openingen die u wilt aftrekken. Deze module maakt de rekensom zichtbaar. De uitkomst is een geometrische hoeveelheid; spreek met uw stukadoor apart af welke meetmethode voor de offerte geldt.

SC-M10

Offertebedragen per regel optellen met expliciete btw-invoer

Een offerte kan verschillende posten bevatten. Voer het nettobedrag en het overeengekomen btw-percentage per post zelf in. De module laat de optelling en de afronding zien. Hij kiest geen wettelijk tarief voor uw woning of werkzaamheden.

SK-M10

Een werkvolgorde controleren op ontbrekende stappen en cirkels

Leg vast welke stap op een andere stap wacht. De module controleert of alle genoemde stappen bestaan en of de afhankelijkheden een uitvoerbare volgorde toelaten. Een eenvoudige lijst kan zo zichtbaar maken dat twee afspraken onbedoeld op elkaar wachten.

CL-M10

Schoonmaaktaken verdelen in inbegrepen, uitgesloten en te bespreken

Een taak die nog besproken moet worden, is niet automatisch inbegrepen. Dit werkblad houdt de drie statussen gescheiden. Noteer per ruimte een concrete taak en kies één status. De code accepteert geen vierde status en signaleert dubbele ruimte-taakcombinaties.

Code lokaal controleren

git clone https://github.com/arek1985/cost-guide-open-tools.git
cd cost-guide-open-tools
node --test

Gebruik Node.js 20 of nieuwer. De voorbeeldpagina’s gebruiken JavaScript-modules; open ze via een lokale webserver of de gepubliceerde projectsite. De volledige code en tests blijven ook als gewone bestanden leesbaar.
